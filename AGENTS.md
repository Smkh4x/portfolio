# Project Context

## Overview

VS Code Inspired Developer Portfolio

## Tech Stack

- React
- Tailwind CSS
- Framer Motion

## Design System

The UI must look like Visual Studio Code.

### Colors

- Background: #1e1e1e
- Sidebar: #252526
- Activity Bar: #181818
- Accent: #007acc
- Text: #d4d4d4

### Layout

- Left Activity Bar
- Explorer Sidebar
- Top Tabs
- Code Editor
- Status Bar

### UI Rules

- Use JetBrains Mono font
- Use VSCode spacing
- Use VSCode style icons
- No rounded modern SaaS cards
- No glassmorphism
- No bright gradients
- Keep everything developer-focused

### Components

- Sidebar
- Explorer
- EditorTabs
- CodeWindow
- Terminal
- StatusBar

## Goal

The portfolio should feel like a real VS Code workspace.
Visitors should feel they are browsing source code.
